# 08 多模态 AI

## 1. 多模态能力

多模态模型处理文本、图片、音频、视频或文档布局，常见链路：

```text
上传 -> 类型/大小/病毒检查 -> 存储 -> 模态模型 -> 结构化结果
```

多模态输入需要明确 MIME、大小、分辨率、页数、时长、语言和数据保留策略。

## 2. 图片理解

适合图片问答、截图分析、商品质检、票据识别和图表解释。图片 URL 必须使用短期签名或后端代理，不能把内部地址和长期凭据交给模型。

输出不能直接作为财务、身份和安全决定。OCR 数字、表格和小字容易出错，应保留原图、框坐标和人工复核流程。

## 3. 文档理解

PDF/扫描件处理通常是：

```text
文件 -> 病毒扫描 -> OCR/布局解析 -> 表格/页眉识别
     -> 结构化 JSON + 原文引用 -> RAG/业务系统
```

不要只把 PDF 转纯文本，表格行列、页码和章节路径决定后续检索质量。文档解析结果需要 Schema 校验和抽样人工验收。

## 4. 语音

- ASR：语音转文字，关注语言、方言、说话人和时间戳。
- TTS：文字转语音，关注音色、延迟、缓存和内容安全。
- 音频流：使用分片、背压和取消，避免全量缓冲导致延迟。

会议摘要要区分说话人、时间和原始音频引用。录音涉及隐私、授权和存储保留。

## 5. 多模态 RAG

文档的图片、表格和文本可以分别索引，再在回答时组合：

```text
文本召回 + 表格检索 + 图片/页截图
        -> 统一引用和权限 -> 多模态模型
```

引用必须指向文档、页码、表格或图片区域，而不是只返回模型生成的描述。

## 6. 成本与安全

- 限制图片分辨率、PDF 页数、音频时长和并发。
- 上传内容使用对象存储短期 URL，不把原始数据写入普通日志。
- 图片和音频同样可能包含 Prompt Injection 或敏感信息。
- 下载远程 URL 时限制协议、域名、大小和重定向，防止 SSRF。
- 对模型输出的 Markdown、HTML、代码和 OCR 结果进行安全处理。

## 7. 生产检查清单

- [ ] 输入类型、大小、格式、分辨率和时长有限制。
- [ ] 原文、页码、区域和说话人信息可追溯。
- [ ] OCR、表格和视觉结果经过结构化校验。
- [ ] 多模态数据权限、保留和删除策略明确。
- [ ] 处理耗时、Token、费用、失败和人工复核可观测。
